# C13 garden gameplay checkpoint — 7 September 2026

This Windows / Unreal Engine 5.8 checkpoint packages the current garden changes for immediate playtesting. It is not the completed art overhaul.

## Changes since C12

- Rebuilt continuous terrain with shaped banks and access ramps into the lower planted areas. Native collision analysis connects all nine named destinations.
- Smaller planting, revised individual paving stones and new material families for terrain, stone, tissue, foliage and water.
- Revised movable sunlight, skylight and local lighting, with Lumen quality settings and contact shadows.
- Repaired two terrain meshes with reversed collision-facing surfaces that previously let Attention fall through.
- Retains faster movement, the physical cape, bright-thought carrying, heavy-thought pushing and pulling, focus interaction, worry release and the return bridge loop.

## Honest limits

The garden's art, brain envelope, planting, surfaces and lighting still need substantial refinement against the concepts. The newly authored fitted cortex remains outside this immediate package. Native collision analysis is separate from an input-driven playthrough; consult the accompanying build manifest for actual test results. Physical controller use remains untested. Cape cloth has local body and thought clearance, but no arbitrary scenery or self collision. Automated contact checks are not animation-quality acceptance.

C12 remains unchanged. Packaged test reports, screenshots, relevant source snapshots and package hashes accompany C13 in its Evidence directory.
